# Council extracts — working rules

> **Empty by design.** The Council negotiating mandate on file 2025/0359 (COD) is **ST 7322/26**
> (13 Mar 2026, committed under [`../../sources/council/`](../../sources/council/)); the file moved
> to trilogue and provisional agreement before any further Presidency compromise rounds. The
> politically agreed text is transcribed in [`../agreed/`](../agreed/) instead. If a Council text
> ever needs its own extract set (e.g. for a Commission-vs-mandate comparison), it gets an
> identically-structured set (`ST-<nnnn>-<yyyy>_<slice>.md`, one file per `tracker.yaml`
> `extract_slices`), produced with the `transcribe-council-extract` skill.

Before adding or editing any file in this directory, read
[`_TRANSCRIPTION_GUIDE.md`](./_TRANSCRIPTION_GUIDE.md) and follow it. It is the canonical
standard for transcribing compromise-text extracts (source of truth, consolidated
reading, faithfulness rules, structure/anchors, header block, cross-links).
