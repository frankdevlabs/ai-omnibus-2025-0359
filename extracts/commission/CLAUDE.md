# Commission extracts — working rules

> The base-text extract set for **COM(2025) 836 final** lives here: one file per `tracker.yaml`
> `extract_slices` (`COM-2025-836_<slice>.md`). These extracts are the diff baseline for the
> agreed-text set in [`../agreed/`](../agreed/) and any future `../council/` sets. Cross-check
> against the committed PDF under [`../../sources/commission/`](../../sources/commission/) before
> relying on any passage.

Before adding or editing any file in this directory, read
[`_TRANSCRIPTION_GUIDE.md`](./_TRANSCRIPTION_GUIDE.md) and follow it. It adapts the canonical
[`../council/_TRANSCRIPTION_GUIDE.md`](../council/_TRANSCRIPTION_GUIDE.md) for the **base text** —
the Commission proposal **COM(2025) 836 final** that the Council mandate, EP position and the
provisional agreement all amend.
