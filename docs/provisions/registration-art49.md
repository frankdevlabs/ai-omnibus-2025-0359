# Registration of self-assessed non-high-risk systems (Art 6(3) / Art 49, Annex VIII)

Operative text: [Commission](../../extracts/commission/COM-2025-836_registration-art49-annexviii.md) ·
[agreed](../../extracts/agreed/PE-789081_registration-art49-annexviii.md)

| Lane | Position |
|---|---|
| **Current law (AI Act)** | A provider who self-assesses an Annex III system as *not* high-risk (narrow/procedural tasks) must register it in the EU database |
| **Commission** | **Scrap** that registration duty |
| **EDPB–EDPS (JO 1/2026)** | Keep it — scrapping gives providers *"an undesirable incentive ... to unduly invoke this exemption"* |
| **Council + Parliament** | **Restore** the duty |
| **Agreed (PE789.081)** | Restored, with **simplified information requirements** (Annex VIII Section B) — a self-assessment "not high-risk" stays a public database entry |

One of the clearest cases of the advisory bodies reversing a Commission easement —
