implementation of the AI Act"; COM(2025) 837 = data/cyber "simplification") and the new entry is on the
AI file this repo tracks, not the `keep_apart` sibling 2025/0360.

The underlying fact — that the EP plenary 1st-reading vote was **held on 16 Jun 2026** — is corroborated
by a **primary source**: the Oeil procedure file records *"Results of vote in Parliament"* dated
**16/06/2026**. This is exactly the headline pending milestone the repo flagged as *indicative / "not
held as of 15 Jun" / not yet confirmed*. MediaLaws (Tier-2) is the trigger; Oeil is the authority.

Caveat: Oeil so far shows only the *vote result*. The formal "Texts adopted, 1st reading" document and
its T-number for the 16 Jun resolution are **not yet quotable** (the only adopted-text T-number on file,
T10-0098/2026, is the 26 Mar 2026 negotiating-position partial vote). So we record the vote as held but
flag the adopted-text T-number and any divergence from PE789.081 as still to be verified.
